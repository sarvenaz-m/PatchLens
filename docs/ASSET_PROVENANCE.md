# Asset provenance and design

## Code-native banner

`github-banner.svg` is generated by `scripts/make_banner.py` from `examples/repository-cross-validation/cross-validation-summary.json`. Its 56.0% score and six zero-to-100% bars are repository macro balanced accuracy; misses/alarms are actual pooled counts. It is a vector repository banner, not a browser screenshot. It contains no remote resources or executable code.

## Native interface assets

`src/patchlens/web/assets/mark.svg` is an original vector mark under the project MIT licence. The interface uses system fonts and native SVG charts without CDN fonts, remote icons, tracking pixels or network-loaded dependencies.

| Role | Colour |

| Ink / navigation | `#142734` |

Colour accompanies text labels and counts. Dark appearance has its own palette; reduced-motion preferences and visible keyboard focus are supported.

## Data graphics

`public-results.png` and `.svg` are generated by `scripts/make_public_figures.py` using Matplotlib 3.10.8 and actual five-fold summary values. The accuracy axis runs from 0% to 100%; error bars are the 2,000-draw whole-repository percentile intervals. The second panel shows pooled errors with 62 contexts per class. The paired difference interval includes zero. These are plotted data, not generated imagery.

`reference-results.png` and `.svg`, generated by `scripts/make_figures.py`, preserve the historical authored reference result and its descriptive Wilson intervals. They do not illustrate public-study performance.

## Actual v2 browser captures

The ten `workbench-*.png` screenshots are actual version-2 interface captures using Playwright 1.62.1 and Chrome 154.0.8037.92. Desktop pages use 1440 × 1080 with full-page captures; mobile captures use a 390 × 844 viewport. `workbench-benchmark.png` and `workbench-benchmark-mobile.png` show the new public study. Other captures show the public reference report, including its errors. `scripts/capture-ui.cjs` opens a fresh session without reviewer annotations.

`workbench-tour.webm` records actual browser navigation, public results, source search, threshold exploration/reset and model views. `workbench-preview.gif` is an FFmpeg resize/quantization of the first 20.6 seconds of that recording; it does not fabricate UI frames. Scripts for capture, recording and conversion are included. The self-contained `index.html` powers both the offline demo and GitHub Pages.
